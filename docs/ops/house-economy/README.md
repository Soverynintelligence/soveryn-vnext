# House economy — burn vs return

**Purpose:** Decide upgrades with a ledger, not vibes.  
**Scoreboard:** Can the house fund its own power, hardware amortization, and the next upgrade — without forever eating Jon’s attention for free?

Not a “bot salary” story. A sovereign ops desk that either **makes cash** or **avoids cash**, then parks surplus in an **upgrade fund**.

Related: [ActTruth tiers](../../act-truth-product-tiers.md) · [three-way borrow list](../../notes/2026-08-20-hermes-rakazo-soveryn-three-way.md) · [bug triage](../../designs/2026-08-20-acttruth-bug-triage.md)

## Monthly ritual (15 minutes)

1. Copy `TEMPLATE.md` → `YYYY-MM.md` (e.g. `2026-08.md`).
2. Fill **Burn** (rough is fine — order-of-magnitude beats fiction).
3. Fill **Return** (cash in + hours saved × your hourly opportunity cost).
4. Compute **Net** and move surplus to **Upgrade fund** (or cut duties if red).
5. One line: **what we buy next only if fund clears the bar.**

## Operating rules

1. Every new duty names a **$ or hours** hypothesis before it ships.
2. Egress (email, Signal, X, pay) stays behind **Approval Gate** / held pile until earned.
3. ActTruth proves what ran; triage closes loops so burn doesn’t become retry waste.
4. Hardware upgrades require **fund ≥ ticket** (or an explicit Jon override noted in the month file).

## Paths that count as return

| Path | Count as |
|------|----------|
| CWG sales / booked work attributable to house content or drafts | Cash |
| Hours not spent on briefs, triage, captions, planning | Avoided cost |
| ActTruth wire-up / house install / retainer | Cash |
| Mistakes not shipped (caught by Vett / gate / triage) | Avoided cost (estimate) |
| SaaS you cancelled because the house replaced it | Avoided cost |

## What does not count

- Demo wow, Twitter ROI flex, “the bot feels smart”
- Unattended outbound that isn’t gated
- Buying GPUs because the queue *might* need them
