# Handoff Note Template (2026-08-24 format)

Use this template for end-of-session handoff notes in `docs/notes/`.

## Shipped
- What was completed this session (files, features, fixes).

## Hardware
- Which machines/weights were used; anything that changed on the rack.

## Public
- Anything customer-facing that changed (site, brand, quote process).

## Local-only
- Internal work not visible publicly.

## Next
- The next agent's first three moves.

Rule: notes are not authority. If live state changed, update `docs/CURRENT_TRUTH.md` — the note records history, CURRENT_TRUTH records now.
