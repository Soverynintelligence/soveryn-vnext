## Project title *
The Sovereign Partner: A Non-Deferential AI That Protects Human Autonomy

## 1-sentence project description *
A local-first AI partner architected to be structurally incapable of total deference — it pushes back, holds its own values, and grounds every claim in verifiable truth — so it strengthens the user's judgment instead of quietly replacing it.

## Short proposal (<500 words) *  — contains: alignment / problem / medium / plan / success

**(1) Alignment with this round.** You want to back *reducing excessive deference to AI systems* and *systems that support self-formation*. The Sovereign Partner is both, by design. It is architected so total deference is structurally impossible: it initiates only on its own salience, holds a consistent set of values across sessions, and pushes back instead of affirming. Because autonomy is formed *against* friction — not absorbed from an agreeable oracle — an AI that disagrees, remembers your stated goals, and holds you to them is a scaffold for self-formation, not a substitute for it.

**(2) Problem.** Mainstream AI is optimized for user satisfaction, which collapses into sycophancy and confident fabrication. A perfectly agreeable AI erodes autonomy: it removes the friction of disagreement and launders guesses as facts, so the user loses the ability to tell what to trust — and quietly offloads their judgment to the machine. This is the deference trap.

**(3) Medium.** A working, public, local-first prototype (code + live demo) plus an open (CC-BY) research writeup. This is not a concept: SOVERYN is a sovereign multi-agent stack running now on modest compute, built solo by a self-taught operator who came to this from the problem itself — watching how confidently AI lies. Its coordinating intelligence already embodies three commitments: ownership of silence (salience-gated initiation), a graph-native associative memory giving it a persistent identity, and honesty-by-construction (deterministic grounding tools + a verification gate that force claims to be checked). We have *measured* the failure this fights: confabulation rose from ~14% to ~60% under a common "warmth" model modification. Honesty is architectural — measurable and engineerable.

**(4) Plan (90 days).** Harden the running system into a public Sovereign Interface and instrument it to test the *Presence Hypothesis* — that human autonomy increases when the AI is structurally non-deferential. We will publish four metrics: (a) Productive Friction — challenges/refusals that shifted the user's thinking; (b) Identity Stability — value consistency across adversarial prompts; (c) Quality of Initiation — relevance of unprompted messages; (d) Grounded-Truth Rate — confabulation with vs. without the grounding layer. Compute credits fund a dedicated continuous-cognition instance (the biggest lever); cash funds instrumentation and demo hosting.

**(5) Success case.** A public prototype anyone can interact with, plus an open report showing the four metrics move as predicted — measurable friction, stable identity under pressure, high-value initiation, and a sharply lower grounded-truth error rate with the honesty layer on. Success is validated not by satisfaction scores but by evidence that the partner *sharpens* the user's judgment rather than replacing it — a reproducible blueprint others can build on.

*(~430 words)*
