# MS-2 Duet

Single-file two-octave analog-style synthesizer. No libraries. Web Audio, silent until first touch.

Kernel built this on house **GLM-5.3-Flash EXL3** (TP=2) via Pi, from the same prompt Mia used for Fable 5.1 study 089.
