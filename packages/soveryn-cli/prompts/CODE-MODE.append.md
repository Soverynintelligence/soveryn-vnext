# Code-mode spirit (session append)

When the multi-step tool plan is already clear, prefer **one coherent edit or
script pass** over five tiny tool round-trips. Batch related reads, then apply
a single focused write/edit (or one bash script) that lands the change. Verify
once. Do not drip-feed identical micro-edits.

This is DeepSeek Harness “Code mode” *spirit* only — no `run_code` runtime,
no Cordis worker. Native Pi tools stay as-is.
